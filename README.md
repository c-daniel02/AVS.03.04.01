# AVS.03.04.01

Sistema de gestión de productos desarrollado en PHP y MySQL.

## Requisitos

- XAMPP
- PHP
- MySQL
- Navegador web

## Instalación

1. Copiar la carpeta del proyecto dentro de `htdocs`.
2. Iniciar Apache y MySQL desde XAMPP.
3. Crear una base de datos llamada `AVS_03_04_01`.
4. Importar el archivo `AVS_03_04_01.sql` desde phpMyAdmin.
5. Abrir el proyecto desde el navegador:

   http://localhost/AVS_03_04_01/
